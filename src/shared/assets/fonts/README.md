# Bundled Font

`OpenSans-CondensedLight.ttf` is bundled so AutoCAD drawings that use SHX
fonts can be rewritten with a Unicode-capable text style.

- Font: Open Sans Condensed Light
- Designer: Steve Matteson / Ascender Corporation
- Source: https://github.com/googlefonts/opensans/raw/main/fonts/ttf/OpenSans-CondensedLight.ttf
- License: Apache License 2.0
- SHA256: `BD09013EBB713EF8BDF17FD7BAC92E51A6FF2F2E6844F561AE0CDA2A457A9ED0`

The runtime only downloads this file as a fallback when it is not installed or
bundled, and verifies the SHA256 before using the downloaded copy.
