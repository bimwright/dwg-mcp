## How to read the numbers

- **Duration**: end-to-end milliseconds seen by the MCP client (server + Named Pipe + AutoCAD + handler). Repeatable calls ran 3 times: *cold* is the first call, *warm p50* the median of the rest.
- **Result size**: UTF-8 bytes of the text content the agent receives (inline images are not counted). Result content is never recorded here.
- **Est. tokens**: `ceil(bytes / 4)`, a rough rule of thumb for JSON text.
- **Status**: *Success* when the call returned its normal result, or — for rows marked *error path* — the error code the design calls for. *Failed* otherwise.
- **Size policy**: `warning` / `strong warning` when the server marked a large response, `rejected` for `RESPONSE_TOO_LARGE`, otherwise `none`.
- Write tools ran on the disposable drawing only; no user drawing was opened or saved.
